# LexBudget — SmartBudget Mobile (v1.4.0)

Application mobile (PWA) de gestion budgétaire personnelle basée sur la règle **50/30/20**, avec gestion multi-projets mensuels, report de soldes (*Rollover*), synchronisation Cloud Firebase en temps réel, audit financier IA et système de **mise à jour directe via GitHub (`Check Update`)**.

📖 **[Consulter la Documentation Complète (DOCUMENTATION.md)](./DOCUMENTATION.md)**

---

## Fonctionnalités Principales

- **Méthode 50/30/20 & Stratégies sur mesure** : Répartition dynamique entre *Besoins*, *Envies* et *Épargne* avec curseurs personnalisables.
- **Indicateur "Safe-to-Spend" Quotidien** : Calcul en temps réel du budget journalier disponible (`~X TND/j`) jusqu'à la fin du mois.
- **Multi-Projets Mensuels & Reports (`Rollover`)** : Créez et archivez vos périodes mensuelles sans perte d'historique, avec report global ou poste par poste.
- **Charges Fixes & Échéancier** : Suivez vos factures mensuelles et validez leur paiement en un clic.
- **Multi-Portefeuilles & Virements** : Gérez vos espèces, comptes bancaires et cartes avec virements internes.
- **Audit IA & Simulateur "What-If"** : Diagnostiquez votre santé financière et simulez vos gains d'épargne mensuels et annuels.
- **Check Update synchronisé avec GitHub** : Vérifiez les nouveaux commits de votre dépôt GitHub directement depuis votre téléphone et mettez à jour l'application en 1 clic sans aucune perte de données.

## Démarrage Rapide

```bash
# Installation des dépendances
npm install

# Lancement du serveur de développement (http://localhost:3000)
npm run dev

# Vérification TypeScript & Build de production
npm run lint
npm run build
```
